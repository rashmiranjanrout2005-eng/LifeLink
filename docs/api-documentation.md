# API Documentation

Base URL: /api

## Authentication
- POST /auth/register
- POST /auth/login
- POST /auth/logout
- GET /auth/me

## Donors
- GET /donors
- POST /donors
- PUT /donors/:id

## Inventory
- GET /inventory
- GET /inventory/availability
- POST /inventory
- PUT /inventory/:id

## Requests
- GET /requests
- POST /requests
- PUT /requests/:id/status
